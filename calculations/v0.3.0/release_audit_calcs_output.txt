========================================================================================
3. Fault cases
========================================================================================
+3V3_P shorted: eFuse limits input to <= 0.69 A -> LDO P <= 3.62 W -> Tj reaches
  TSD 165 C (SBVS160C p.5): TLV1117LV thermal shutdown cycles (current limit 1.1 A typ p.1; short duration 'Indefinite' p.4).
+5V_P shorted: TPS26600 current limit 0.51-0.69 A, P = VIN x I <= 3.62 W ->
  thermal shutdown, auto-retry (MODE = RTN, TI SLVSDG2G Table 2). Board-level: self-protecting, NOT TESTED.
Total +5V_P budget before current limit (min): 510 mA; available for LDO + J3 sensor: 488 mA

========================================================================================
4. Reverse polarity: which paths are inside the eFuse protection
========================================================================================
Floating (isolated) source reversed: VIN_RAW = -V vs board GND; TPS26600 blocks to -60 V; no other path -> PROTECTED (design).
Earth-referenced source (negative terminal earthed) reversed while the ESP32 USB host is earthed:
  source +  -> J1-2 (board GND) -> J2-2/11/12 -> DevKit GND -> USB GND -> host earth -> source -  (loop)
  The eFuse is NOT in this loop. Current is limited only by the source current limit and the cable/USB path.
  -> NOT PROTECTED. Mitigation: isolated supply, polarity check before USB connection (power-up order R-31).
